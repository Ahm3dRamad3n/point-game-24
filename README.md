## 📖 About The Project

**Point Game 24** is a simple yet highly engaging number puzzle game. The challenge? Players must use four given numbers and three fundamental arithmetic operations (Addition, Subtraction, Multiplication, Division) to reach the exact result of **24**.

Developed as a fully functional **Progressive Web App (PWA)**, it offers a native-like experience, allowing users to install the game on any device (desktop or smartphone) and enjoy it seamlessly, even offline.

## ✨ Features

* 🧠 **Mental Challenge:** Sharpen your math skills with endless puzzle combinations.
* 📱 **PWA Ready:** Installable directly from the browser to your home screen or desktop.
* 📴 **Offline Support:** Play anywhere, anytime, without needing an internet connection.
* 🎨 **Clean UI/UX:** A minimalist, distraction-free interface focused entirely on gameplay.
* 📐 **Responsive Design:** Fluidly adapts to any screen size or orientation.
