# Point Game 24
---
## About The Project

Point Game 24 is a simple and engaging number puzzle game where players challenge themselves to use four given numbers and three arithmetic operations (addition, subtraction, multiplication, division) to achieve the result of 24. The game is developed as a Progressive Web App (PWA), allowing it to be installed on various devices (desktops and smartphones) and accessed even when offline.

## Features

*   **Simple and Fun Puzzle Game**: A mental challenge to sharpen your math skills.
*   **Progressive Web App (PWA)**: Can be installed on your device and accessed anytime.
*   **Offline Support**: Play anywhere without an internet connection.
*   **Clean and Intuitive User Interface**: A minimalist design focused on the gaming experience.
*   **Responsive Design**: Works seamlessly across different screen sizes.
